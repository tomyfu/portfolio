AiFX

시장 신호가 언제 켜지고 사라지는지 한 화면에서 따라가는 Windows 관제 프로그램.

작업 정보

기술과 도구

Windows x64 · HTML · JavaScript

산출물

AiFX_Native_v01_x64.exe · AiFX_Demo.html

풀고 싶었던 문제

매수 표시 하나만으로는 어떤 조건이 충족됐는지, 다음 봉에서도 그 판단이 유효한지 설명하기 어려웠습니다.

내가 맡은 일

종목 선택, 시세 차트, 판단 근거, 신호 기록을 한 흐름으로 설계했습니다. 브라우저에서 조작감을 먼저 확인하고 Windows x64 네이티브 창으로 확장했습니다.

결과

네이티브 시제품에서는 캔들을 선택하고 EMA 20이나 분석 표시를 전환할 수 있습니다. 공개한 브라우저판에서는 예시 GBP/USD 시세를 한 봉씩 넘기며 대기, 진입 후보, 구간 이탈을 확인할 수 있습니다.

공개 데모는 고정된 예시 시세를 사용합니다. MT5 실시간 체결은 후속 연동 범위입니다.
